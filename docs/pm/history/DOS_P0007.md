## What was learned

**The correct package command is `npm run package` from repo root**, not `npm run -w deliveryos package`. The root script calls `node scripts/build.mjs` first, which copies webview assets into `extension/dist/webview/`. Skipping this step produces a 12-file VSIX missing all webview panels.

**The dogfood arc exposes real gaps fast.** Four bugs found in one session of using the extension. The copy-paste-prompt workflow (discovery → PRD) is coherent but has sharp UX edges: no escape hatches, non-obvious auto-save, dead-end approval buttons.

**PRD sections are editable textareas with 500ms debounced auto-save.** No explicit Save button — "Saving…" / "Saved" appears in the section header. Users looking for a Save button assume the field is read-only.

**`.deliveryos/memory/requirement/` is written by the extension on disk** as markdown companion files alongside the SQLite entries. These should be tracked (or .gitignored) deliberately — they appeared as untracked at wrap time.
