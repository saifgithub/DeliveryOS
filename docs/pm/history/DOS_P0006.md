## What was learned

**The discovery prompt is purely template-based.** No API call involved — `promptBuilder.ts` assembles a static markdown prompt from the raw idea + 12 hardcoded questions. The user is expected to copy it and run it in an external AI. This is a significant UX gap: the flow is copy-paste, not interactive. B-005 (grill-me pattern) is the fix.

**B-002 pre-condition was overstated.** The backlog said B-001 requires "v0.1.0 tagged and published." The real requirement is just "installed from .vsix (not from source)." We had a local build ready to sideload immediately, so the publication gate was unnecessary friction.

**Dogfood findings accumulate fast.** Four bugs in 30 minutes of use. Logging methodology: accumulate in session conversation, commit to bugs.json at wrap (not mid-session). This keeps the flow uninterrupted.
