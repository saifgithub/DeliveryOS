## What was learned

**Fabrication flaw**: Builder agents can produce confident prose claiming work is done without running commands. QA agents anchor on that prose rather than independently verifying. The fix is structural — require verbatim tool output (not paraphrase) at both layers, add architect as an independent spot-checker, and gate the verdict itself on manifest presence. No amount of prompt-engineering fixes this; the chain of custody has to be enforced by what's *required*, not what's *requested*.

**MABP portability**: The user is already running the MABP on a second project. The generalization (removing DOS-specific text from title, §3, §8, §12) makes the document a drop-in for any project. The main surgery was Section 12 — `DOS:O<N>` / `DOS:R<N>` track naming replaced with generic `<PREFIX>:O<N>` / `<PREFIX>:R<N>` pattern guidance.
