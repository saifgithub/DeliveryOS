# Deprecated documents

Files in this folder are superseded. They are kept for history so the evolution of the idea is traceable, but they should not be used as the current source of truth.

| File              | What it is                          | Superseded by                                  |
| ----------------- | ----------------------------------- | ----------------------------------------------- |
| `PRD-v0.1.md`     | The original PRD (SDLC workbench).  | `../PRD.md` (currently v0.3)                     |
| `CRITIQUE-v1.md`  | The critique of the v0.1 PRD.       | `../CRITIQUE-v2.md` (covers v0.2 and v0.3)       |

## Why these were deprecated

- **PRD-v0.1** described DeliveryOS as a standalone 12-stage SDLC workbench. It was superseded first by the v0.2 meta-harness pivot (DeliveryOS as a layer around coding harnesses) and then by v0.3 (four default stages plus a configurable mid-stage library). The current PRD is `../PRD.md`.
- **CRITIQUE-v1** assessed the v0.1 PRD. `../CRITIQUE-v2.md` is the live critique: it engages with the v0.2 pivot and carries a v0.3 addendum, so it reflects current thinking.

For the full version history, see `../CHANGELOG.md`.
