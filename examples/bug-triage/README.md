# Bug Triage Assistant — Demo Target

This is the demo target repo for the DeliveryOS live walkthrough. It provides a
minimal FastAPI backend that an AI coding agent will implement during the demo.

## Role

`examples/bug-triage/` plays the role of the **user's existing project**.
DeliveryOS is sideloaded into VS Code, this folder is opened as the workspace,
and the recording captures the full SDLC flow from raw idea to deployed test.

## Install

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
```

## Test command

```bash
pytest -q
```

## Lint command

```bash
ruff check .
```

## Initial state

The project skeleton ships with:

- `src/backend/app.py` — FastAPI app factory (no `/bugs` router yet)
- `src/backend/api/users.py` — reference thin-handler pattern (do not modify)
- `src/backend/core/auth.py` — existing bearer-token middleware (do not modify)
- `src/backend/core/db.py` — existing repository-pattern stub (do not modify)
- `migrations/0001_init.sql` — existing DB migration (do not modify)
- `src/frontend/placeholder.tsx` — frontend stub (out of scope for this demo)

The following files are **created by the AI agent during the demo run**:

- `src/backend/api/bugs.py`
- `src/backend/models/bug_report.py`
- `src/backend/services/bug_report_service.py`
- `tests/integration/test_bugs_api.py`

## Reset between takes

```bash
bash scripts/reset-demo.sh
```

The reset script restores the skeleton and removes the four files created
during the demo run. It refuses to run if there are uncommitted changes outside
`examples/bug-triage/` to protect unrelated work in progress.

## DeliveryOS memory store

`.deliveryos/` contains a pre-seeded SQLite store with two memory entries:

- **Intent Memory** — project name "Bug Triage Assistant", raw idea, and
  pre-filled discovery answers.
- **Codebase Memory** — folder layout, conventions, test runner, auth module,
  and known constraints.

The store was generated by `scripts/seed-demo.ts` from
`scripts/seed-demo.source.yml`. To regenerate:

```bash
cd examples/bug-triage
npx tsx scripts/seed-demo.ts
```
